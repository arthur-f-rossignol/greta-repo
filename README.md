# Repository for `greta` (version 0.5.0)

This repository contains the binary files of the R package `greta` v0.5.0 (Golding _et al._, 2024), which are necessary for using the R package `runMCMCbtadjust` (Gosselin, 2025). Such a procedure was suggested in [this page](https://andrewzm.wordpress.com/2017/02/04/packages-in-non-standard-repositories-what-to-do-when-submitting-your-own-r-package-to-cran/) so as to have one's package available in the CRAN even though it depends on a package that is not on the CRAN. Additionnaly, the R package `drat` v0.2.5 (Eddelbuettel _et al._, 2024) was used according to [this page](https://blog.thecoatlessprofessor.com/programming/r/r-data-packages-in-external-data-repositories-using-the-additional-repositories-field/index.html).
