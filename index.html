Repository for greta (version 0.5.0)

This repository contains the binary files of the R package greta v0.5.0 (Golding et al., 2024), which are necessary for using the R package runMCMCbtadjust (Gosselin, 2025). Such a procedure was suggested in this page so as to have one's package available in the CRAN even though it depends on a package that is not on the CRAN. Additionally, the R package drat v0.2.5 (Eddelbuettel et al., 2024) was used according to this page.
